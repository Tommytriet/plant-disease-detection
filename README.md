# Abstract
For object detection, training and accurately identifying small objects remains a major challenge. Several prior works have attempted to address this issue by introducing additional attention blocks or redesigning the entire network architecture; however, such approaches often incur substantial computational costs. To mitigate this problem, we propose an improved model, YOLOv5_improve. The method is based on three key modifications. First, an additional prediction head dedicated to small object detection (SODH) is integrated into the YOLOv5 head to generate high-resolution feature maps, thereby enhancing detection performance for small objects. Second, an Involution blockis inserted between the backbone and neck to strengthen the channel-wise representation of the feature maps. Finally, a Convolutional Block Attention Module (CBAM) is applied at the end of the backbone, enabling more efficient attention modeling while maintaining lower computational overhead compared to prior approaches.
